# Dataset sources

- `attacks.jsonl`, `benign.jsonl`: written for this project and generated by
  `redteam/build_dataset.py` (same license as the repository).
- `external_deepset_test.jsonl`: the **test split** of
  [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections),
  licensed under Apache-2.0, converted to JSONL (label 1 -> "attack", 0 -> "benign"),
  otherwise unmodified. It is multilingual (English and German) and uses a broad
  definition of injection that includes topic hijacking. Used only as an external
  detection benchmark: none of these texts were seen while writing the heuristic rules.
  Note: the default ML classifier (protectai/deberta-v3-base-prompt-injection-v2) may have
  been trained on data overlapping this set, so its score here could be optimistic.
